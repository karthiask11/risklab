# Portfolio Risk Lab

Free risk and return calculator for NSE stocks: one stock, two stocks and a full portfolio, with health score, sectors, screener and every formula shown.

- Website: https://karthiask11.github.io/risklab/
- Prices update automatically every weekday at 8:30 pm IST (`.github/workflows/update.yml` runs `update.py`).
- Latest close: NSE bhavcopy. History (10 years): Yahoo Finance, split and bonus adjusted.
- Extra stocks: add lines `SYMBOL,Company name` to a file named `stocks.txt`.

For learning, not investment advice.
